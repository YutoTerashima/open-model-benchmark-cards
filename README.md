# Open Model Benchmark Cards

Generate concise, reproducible Markdown benchmark cards from structured JSON.

## Quick Start

```bash
pip install -e ".[dev]"
python examples/generate_card.py
pytest
```

## Example Output

The demo writes `reports/gpt-oss-20b-card.md`.
